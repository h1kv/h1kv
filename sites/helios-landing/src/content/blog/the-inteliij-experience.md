I recently have begun to focus myself with new IDEs, partly because I want to be fullproofed in knowing how to navigate these IDEs (as no, claude or any agentic AI is going to save you from having to use an IDE). 

My first option was **neovim** and the expereince was quite fun (a hard learning curve though), although I really enjoyed how lightweight and fast it is and the customization and plugin ecosystem. Reminds me of my time using Arch Linux in a terminal only state and configurating it to my liking (old times lol) 

My second option was **pycharm** and it was okay. I guess this is the IDE for python but other than that I didnt really like it. 

My third and final option has been IntelliJ and to be honest I love it so far. It is a quite heavy IDE in resource-wise but I dont think it will be any issues as my workstation is 64GB DDR4, and my current laptop is 32GB DDR5.
